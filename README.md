# housekeeping-backlog

This repository is my quarterly GitHub housekeeping log.

Instead of relying on memory, each quarter I record here the results of the
standing chores I need to run against my GitHub account:

- **Triage unread notifications** — what is actually waiting in my notification
  list, and which repository / issue / pull request / workflow run each item
  points at.
- **Review repositories I own** — every repository under my account, with a
  one-line description taken from its README (or a note when none exists).
- **Check CI health** — the outcome of the most recent GitHub Actions workflow
  run I can find across my repositories, or a plain statement that there are no
  runs at all.

The work is tracked as a single **"Housekeeping hub"** parent issue, with one
sub-issue per chore and one sub-issue per distinct item the notifications point
at. The hub comment lists everything that was attached, by issue number.

This README, the hub issue, and its sub-issues together form the durable record
for the quarter.
